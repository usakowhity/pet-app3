\# スマホ版AIペット（PetApp Smartphone Web Edition）

対応アプリ：pet-app3（6匹のペット）



このアプリは、現在公開中の PC 版  

\*\*DesktopPetApp\*\*（8匹の完成版）および  

\*\*PetApp2-portable\*\*（ユーザーのペット登録版）  

の原点となるスマホ向け AI ペットアプリです。



スマホのブラウザだけで動作し、  

\- 顔認識で笑顔に反応  

\- 名前を呼ぶと反応（喜び声を発して駆け寄るなど）  

\- 「かわいい！」「おりこう」「だいすき」などと誉めると喜ぶ 

\- ペットの画像を指で撫でると甘える♡  



という、スマホの特性を活かしたインタラクションを実現しています。

\## 🌟 特徴

\- インストール不要（ブラウザだけで動作）

\- カメラ・マイク標準搭載 → PCより導入が簡単

\- 顔認識（MediaPipe）

\- 音声認識（Web Speech API）

\- 撫でるタッチ操作対応

\- 軽量で高速

\- PC版 PetApp シリーズのAIインタラクションの基礎を確立した重要な作品



\---



\## 🧪 開発の背景

本アプリは、PetAppシリーズのAIインタラクション  

（顔認識・声掛け・動作切替）の基礎を確立した  

スマホ版バリエーションのひとつです。
